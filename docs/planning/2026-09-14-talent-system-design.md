# 天赋系统设计（卡牌工坊 · 访谈共识 T1~T8，2026-09-14）

访谈结论定稿。实现合同 = 本文档；扩池子/加渠道 = 加数据不改代码。

## 1. 通道（T1/T6/T7）

| 渠道 | 枚举值 | 获得方式 | 独占天赋 |
|---|---|---|---|
| 出身 | `creation` | 捏人向导第 9 步「出身天赋」点选（表内非融合产物） | 【天才卡师】制作成功率+20%（通用） |
| 剧情 | `story` | AI 叙事授予（update_character，白名单） | 【命运宠儿】启封+1/行动值+1/防御+1 |
| 兑换 | `exchange` | 委托板「声望兑换」区，价格 = 条目数×5 点（10/15） | 【卡牌宗师】启封+2/行动值+2 |
| 融合 | `fusion` | 满员时两源融合，唯一来源 | 垃圾摩托 / 封印斗士 |
| 通用 | `universal` | 三渠道皆可 | 节俭持家/摩托小子/封印亲和/斗志昂扬/铜筋铁骨/卡牌大师 |

扩渠道 = 枚举加值 + 数据表加行，不改代码。

## 2. 持有模型（T2）

- **列表 + 容量 3**（数值总表终审对象），照 cardAlbum 容量制先例；
- **同名唯一**（重复习得拒绝）；**叠加无递减**；**部分互斥**（互斥组标签，习得/融合都查）；
- 满员时新天赋 → **融合**或**遗忘**（遗忘无返还、二次确认）。

## 3. 天赋存储形状（两层：表现归 AI，数值归 Code）

```ts
interface TalentEntry {           // 骨架条目（池内预设，AI 零编数）
  kind: '材料限定'|'成品限定'|'成功率加成'|'品质锁定'|'品质突破'
      | '启封加值'|'行动值加成'|'防御加成';
  params: { ...按 kind 预设档位 }; // 如 { bonus: 50 } / { direction: '保底', tier: '普通' }
  channel: TalentChannel;         // 独占标记（universal 可任意渠道获得）
}
interface CharacterTalent {
  name: string;                   // AI 起的叙事名（如【垃圾摩托】）
  description?: string;           // AI 写的表现文案
  source: TalentChannel;
  entries: TalentEntry[];         // 引擎结算只读这一层
}
interface TalentState { capacity: number; list: CharacterTalent[]; }  // CharacterState.talents?
```

## 4. 骨架条目池 v1（T7）

| 域 | 条目 | 预设参数 |
|---|---|---|
| 制作 | 材料限定 | 类别（边角料/废弃），附带成功率+30% 前提 |
| 制作 | 成品限定 | 类别（简单载具/摩托…） |
| 制作 | 成功率加成 | +20% / +30% / +50% |
| 制作 | 品质锁定 | 方向（保底/上限）× 档位（普通） |
| 制作 | 品质突破 | 域限定（摩托/载具…），越一级 |
| 交锋拍 | 启封加值 | +1 / +2 |
| 交锋拍 | 行动值加成 | +2 / +3 |
| 交锋拍 | 防御加值 | +4 |

品质口径（主人确认）：直接用引擎品质档 `普通→优良→稀有→史诗→传说→神话→唯一`（RARITY_LEVELS，不做颜色映射）；制作检定评级为大失败/失败/成功/精益求精（另一维度，勿混）。品质突破的「越一级」按 RARITY_LEVELS 索引 +1，制作上限封在传说（唯一不可生产）。

## 5. 融合 = 条目化学反应（T3/T7）

- 产物条目 = 两源条目合并；**品质锁定(保底) + 品质锁定(上限) → 品质突破**（对消爆发，域限定取两源并集）；
- 其余条目照抄；产物名/描述由 AI 起（一次 AI 调用；**失败/无 API → 玩家自填兜底**，绝不阻塞）；
- 融合消耗两个槽位产出 一个新天赋（容量占用 1）；产物 channel='fusion'（不可兑换/不可捏人）。

## 6. 通道流（T6/T8）

- **出身**：捏人第 9 步，选项 = 通用池 + 出身独占（融合产物除外），纯 UI 零 AI；
- **剧情**：`{{TALENT}}` 注入（现有天赋/容量/可授清单/条目池/融合提示；空时零 token）→ AI 用 update_character 写 `talents`（门禁：条目必须逐字在池内，编数拒绝）；满员时 AI 引导玩家去面板融合/遗忘；
- **兑换**：委托板「声望兑换」区，价格 = 条目数×5（单条目 10、双条目 15），门禁同上 + 声望足够。

## 7. 交锋拍效果（T4）

- 启封加值 → 封印卡出牌的判定加值；行动值加成 → 派生攻击（强攻/出卡直击）；防御加值 → 减伤基数；
- 多天赋**求和**；开场审计行 `▸ 天赋【名】生效：…`（零修正不出行）。

## 8. 制作效果（T4，接 rollCraftRating）

- 成功率加成：按材料限定/成品限定的类别匹配后加到评级判定；
- 品质锁定保底：成品评级低于锁定位 → 抬到锁定位；品质锁定上限：高于锁定位 → 压到锁定位；
- 品质突破：域限定匹配时，成品评级必然越一级；
- 确定性规则、无随机，审计行逐项可复算。

## 9. UI（T8）

- 侧栏「天赋」入口 → 独立 modal：列表（名/描述/条目摘要）+ 容量格 + 遗忘（无返还、二次确认）+ 融合工作台（选两源 → 预览对消 → 执行 → AI 起名，玩家自填兜底）；
- StatusOverview 加天赋名小结行；
- 委托板加「声望兑换」区。
