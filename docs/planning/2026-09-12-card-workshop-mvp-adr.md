# ADR-卡牌工坊：战斗路线与 MVP 边界

- 状态：已采纳（2026-09-12）
- 决策人：atk465
- 关联设计：`2026-09-12-card-workshop-mvp-design.md`

## 背景

要在命定之诗前端承载「卡兰大陆」卡牌制作玩法。两条候选战斗路线：
- **路线 A**：卡牌 = 带 `automata` 的技能池，不碰 combat-v3 主干。
- **路线 B**：真抽牌回合制（手牌/牌库/弃牌三区），深入改 `phases/intents`。

## 决策

**采用路线 A（技术形态），表现力向 B 靠拢（启封式卡组战斗）。**

理由（按杀伤力排序）：
1. 召唤/规则覆写/制作三条通道引擎**已实现且质量高**，路线 A 直接复用，路线 B 需重写状态机。
2. 世界观「巨兽化为伙伴」「禁忌卡颠覆法则」恰好命中 `SpawnOrDespawnIntent` + `requestedRuleOverride`，零改动。
3. 「制卡师亲手炼卡」使「抽牌」的信息不对称前提不成立 → 真抽牌在设定上自相矛盾。
4. 随机性改放「启封判定」，复用现有确定性骰带，且天然形成稀有度平衡杠杆。

## 后果

- 正面：MVP 不碰 combat-v3；复用 `craft-gen-chain` 制作链路；风险低、可独立回滚。
- 负面：非真抽牌；地景卡需后续单独碰 `CombatState`（阶段 4）。
- 权衡已接受：MVP 先行验证可行性，阶段 4 再评估是否深化。

## MVP 边界（明确不做什么）

- 不修改 `combat-v3/` 任何文件。
- 不实现真抽牌（手牌/牌库/弃牌）。
- 不做地景卡、召唤接入、规则覆写（留待后续阶段）。
- 枚举一律集中到 `field-enums.ts`（收口既有 `types.ts` 违反铁律⑤的项）。
