## 三、卡类型与消耗（共识定案）

技能/领域/场景/物资 = **消耗**（哑火不耗、破裂即耗、settlement 结算）；装备/召唤/军团 = **永久**（每打必判、在场绑定重打拒绝）；素材 = 不可战斗打出。

## 八、喂养经济闭环（校验口径）

素材 → 卡（炼制）→ 战斗/交付 → GC+素材+声望 → 更高阶素材。**不变式**：任一档位，
「炼一张卡的成本 ≤ 该卡可完成的委托总收益 × 0.6」——保证供给有利润但刷不过冒险。
真机走查时按实际掉落率校验此比值。
