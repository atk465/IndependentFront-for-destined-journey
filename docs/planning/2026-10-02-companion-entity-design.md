## 〇、事实基线（查证锚点，2026-10-02）

设计建立在以下已查证事实上（文件:行号以当时工作树为准）：

1. **卡牌是 Item 不是实体**：`CardItem extends InventoryItem`（`src/sillytavern/types.ts:1144-1172`），住在 `CharacterState.inventory`；`cardAlbum` 只存卡名数组（owned/deck）。同名卡 ≤2（`card-workshop/album.ts:38-142`）。
2. **首召实体化接缝已在**：打出召唤卡结算后 `buildSummonCompanion` 会 `add_character` 一个 `type:'summon'` CharacterState（tier/level/五维/HP 全为确定性公式，personality 缺省兜底文案），经 `{{CHARACTER_STATE}}` 自动注入叙事（`card-workshop/companion.ts:46-93`、`card-workshop/skirmish-settlement.ts:100-115`）。**但实体不参与交锋数值**。
3. **战斗是单角色拍制**：`roll = d20+行动值+克制`，玩家承伤 `= 威胁−⌊防御/2⌋`（`card-workshop/skirmish.ts:237-293`）；召唤卡打出＝登场直击＋每拍压场 buff 挂玩家行动值（`card-workshop/entry-combat.ts:278-308`）；卡数值基座是**玩家**属性（`deriveCardAtk = 2×主属性+等级`，`card-workshop/derived-stats.ts:88-97`）。
4. **效果池**：`CardEffectDef {trigger,target,action,value,duration,cost,conditions}`（`card-workshop/card-effects.ts:134-146`），**无元素轴**；主动≤2/被动≤2 合计≤4（`:520-547`）；门禁 `coerceCardEffects`（`:557-589`）——池外动作/改数即丢。`target:'敌全体'`（AOE）**已能表达**（`skirmish-session.ts:448-503,1702`）。
5. **好感即伙伴忠诚雏形**：`affection-bond.ts:26-53` 已按 `saveProfile.affections[卡名]` 给召唤卡打出乘共鸣（≥90 ×1.5…≤−10 ×0.8）；AI 记账契约 `set_affection/delta_affection` 在（`state-manager.ts:2003-2032`）；**已知问题：AI 记账保守，纯 AI 来源会长期空转**（bug-list 新观察）。
6. **进化现状**：倾向三选一 炽野/贯城/镜影 固定（`card-workshop/companion-growth.ts:107-119`，存 `card.data.倾向`），被【最终兵器：她】天赋 gate（`game-store.ts:2399-2401`）；投喂 `planFeedCompanion`（同源×2/相生×1.5/相克×0.5，`:183-237`）；经验满管唯一产物 `cardPowerBonus+1`（`skirmish.ts:396-410`）——**「蜕变」没有档位落点**。
7. **品阶链**：`白铁→青铜→白银→鎏金→星辉`（`src/sillytavern/field-enums.ts:29-30`）；全链约 13 张 `Record<CardTier>` 数值表 + 6 处 `indexOf` 顺序敏感点。
8. **结构预留**：`CharacterState.talents` 骨架池结构对伙伴开放（`talent-entry.ts` 注释「缺省=旧档/伙伴无天赋」为既定语义）；`personality/appearance/background` 为自由字符串；`equippedSlot` 在 Item 不在 CharacterState。

## 一、十六项决议

### D1（Q1）访谈范围与产出

本设计只覆盖伙伴实体化＋效果元素轴；CRAFT-1/2 另线修复（现已完成）。产出物＝本设计文档，签核前不落码。

### D2（Q2）模型定位：**实体为主，卡为媒**

`CharacterState(type:'summon')` 是伙伴真身：等级/独立数值/忠诚/性格/装备/进化全在实体上。卡保留品阶/词条/效果池/配方/卡面（图鉴＋工艺语义）。战斗接入点从「从玩家派生」换成「读实体面板」。走完 `companion.ts` 既有方向，不在卡上重造实体语义。

### D3（Q3）卡↔实体对应：**按名对应，获得召唤卡即诞生**

- 对应键＝卡名（与首召实体化条件、`affections[卡名]`、卡册图鉴「同名=同物种拷贝」语义一致）。
- 诞生时机＝**任何入口获得含「召唤」词条的卡**（制卡/购卡/捕获/掉落）→ 立即按卡名 ensure 实体（存在即跳过）。
- 实体的 personality/出身从**制卡叙事**（intent + AI 的 name/desc/narrative）派生；捕获入口用 CompanionSeed(race, temperament)。
- 同名卡 ≤2 拷贝**共享同一实体**（成长账本唯一性的前提）。
- 既有「首召实体化」退役为兼容兜底（防旧档/漏网入口）。

### D4（Q4）实体消亡：**休眠—唤醒**

同名卡全部离手（出售/拆解/战斗消耗）→ 实体转「沉眠」态：停止叙事注入、不可参战，**数据完整保留**。重新获得同名卡 → 唤醒续接（等级/忠诚/进化原样接回）。拆一张还有一张时实体不受影响。换卡/重组卡组不摧毁养成资产。

### D5（Q5）战斗接入：**面板接管基座**

伙伴卡打出的直击/压场/技能，数值基座从玩家属性换成伙伴面板——**公式链形状不动，基座换人**：

- 攻击 → 直击与技能基座；
- MP → 驱动技能 cost（沿用 `CARD_MP_COST_BY_TIER` 与 E 批 cost 通道）；
- 敏捷 → 先攻/克制修正；
- HP → 退场条（语义见 D6）。
  伙伴**不独立行动**（不引入伙伴行为决策面）；改动集中在 `skillContextOf`/`deriveCardAtk` 取数处。友方位独立结算是远期演进，不进本期。

### D6（Q6）生死模型：**挡刀池＋退场不死**

- 默认敌方伤害仍打玩家；满足转移条件时（忠诚门槛/特定被动如「挡刀」/招式指定）伤害改由伙伴承受，伙伴防御入减伤公式。
- HP 归零 → **本场退场**（卡不可再打出）＋实体进入「重伤」态：恢复走修复素材/叙事，**不死亡、不销毁卡**。
- 永久死亡只留给叙事重大事件另行设计，不进引擎默认。
- 「玩家受击」事件源已在（受击时 trigger），挡刀是插在其上的转移判断，不动敌方意图系统。

### D7（Q7）数值生成：**公式锚定＋元素偏置**

- 初始面板总量＝「品阶 × 素材品级合计 × 评级系数」锚定；
- 分布由词条元素决定：火/暗→攻与法强、土→防、风→敏、水→MP（双元素＝双轴分布；火/暗艾拉天然输出型）；
- 全程引擎计算，**面板构成写进制卡审计行**（如 `面板：黑铁基数 × 评级「成功」1.0 → HP…/攻…`），零 AI 介入。
- 升级成长率同样按元素偏置（火系攻速快、土系防速快），见 D8。

### D8（Q8）等级与经验：**成长上实体，伙伴卡经验改道**

- 召唤词条卡的经验入口（投喂 `planFeedCompanion`、战斗分成）**按卡名路由到实体账本**：`entity.exp` 满管 → `level+1`，管容沿用品阶表（CARD_EXP_CAP 形状）；
- 升级时面板按 D7 元素偏置成长率增长；里程碑（技能槽解锁、进化门槛见 D13）挂等级；
- **普通卡的 `cardExp`/`cardPowerBonus` 机制原样不动（零回归）**；
- 旧档召唤卡的存量 `cardExp` 在实体化时一次性折算迁入实体账本。

### D9（Q9）忠诚度：**affections 伙伴视图＋引擎事件加成**

- 不新增存储：忠诚度读 `affections[卡名]`；显示层做量纲映射，**保留负值「怨怼」侧**（黑化叙事空间）；
- **引擎确定性事件直接加忠诚**：投喂成功 +N、并肩战斗结算 +N、挡刀 +N、重伤仍被强制出战 −N；AI 记账只作叙事事件补充通道（绕开已实证的「AI 记账保守→忠诚不动」）；
- 消费点（挡刀门槛/打出共鸣/进化解锁）全读同一账本。

### D10（Q10）装备栏：**背借用＋佩戴引用**

- 装备仍是玩家 inventory 中的物品/装备卡（不转移所有权）；伙伴实体挂「佩戴表」；
- 槽位从简起步：**手部（武器）/身位（防具）/灵位（符）三槽**，后续按需扩展；
- 装备数值并入伙伴面板**加算区**（D7 基数不受影响，卸装即回落）；
- 佩戴中的物品禁止出售/拆解/祭出，需先卸下。不造第二本物品账。
- **已知限制（2026-10-03 执行期裁决）**：佩戴面=**装备卡 only**（手部槽）——`type='装备'` 物品的佩戴通路退役：`equippedSlot` 是物品状态而非固有属性（卸下即失槽位类别，types.ts:1112），引擎无背包装备的固有槽位真源；正确补法=unequip_item 在物品 data 袋记「佩戴槽位」（引擎 op 体改动，属设计层后续项，非补丁）。

### D11（Q11）伙伴天赋：**借用玩家天赋骨架池，AI 叙事派生**

- 复用 `CharacterState.talents` 结构挂伙伴实体，容量 1（后续可扩）；
- 天赋的**名字/描述/机制 kind 由制卡 AI 叙事从骨架池白名单中选定**（延续「AI 只选不改数」纪律）；**params 数值由引擎按品阶/元素定标**；
- 天赋带品阶标号（如 [黑铁]），**随进化档位升级效果**（见 D13）；
- 不可被附魔/精配触碰（那是卡效果池的事）；不走玩家天赋目录抽取。

### D12（Q12）性格：**叙事＋意图软贴合**

- 性格进 `{{CHARACTER_STATE}}`（summon 实体已自动）；
- **交锋意图解析（L2）的伙伴 brief 附带性格关键词**：L2 选技能/打法叙事贴合性格（冷酷→直取要害、暴烈→狂轰）——只影响选择倾向，**不产生数值**；
- 引擎结算完全不读性格（自由文本不入数值）；
- 进化里程碑时允许叙事层刷新性格描述（成长弧光，走既有 AI 写入侧链）。

### D13（Q13）进化：**仪式型**

- 倾向 **archetype 固定三系**（群体爆裂/单体破城/分身共鸣——与炽野/贯城/镜影同构），**名称与描述由 AI 按伙伴出身定制**（艾拉制卡时生成「熔岩炼狱/无心裁决/双生重构」）；
- **解锁条件**：实体等级达当前品阶上限 + 倾向已选 → 「进化卡槽」开放；
- 进化卡槽＝**素材祭品槽**：按已选倾向指定素材类（如火/暗/金属），嵌入 N 张素材卡；投喂经验与祭品是两条并行通道（前者加速等级，后者是仪式要件）；
- 嵌满 + 忠诚 ≥ 阈值 → **进化仪式**（引擎事件）：品阶 +1、面板按新品阶重锚、天赋标号升级、允许性格弧光刷新；
- **【最终兵器：她】保留为额外的战后自动进化线**（既有语义），不再 gate 常规仪式——玩家天赋是加速器，不是门票。

### D14（Q14）品阶：**黑铁全面替换白铁（不新增档位）**

- 五档变更为 `黑铁→青铜→白银→鎏金→星辉`；索引语义与全链数值表**取值不变，仅键名替换**；
- 伙伴「获得即诞生」一律从黑铁起步（新生、未开锋——呼应残偶出身叙事）；
- 存量旧档 `cardTier:'白铁'`：**读取时兼容映射 + 落库时改写**（零一次性迁移风险）；
- 内容包/预设/文案中的「白铁」引用全文排查（含转生点计价注释、世界书词条）。

### D15（Q15）混合伤害：**效果加可选元素轴，克制取优**

- `CardEffectDef` 增加可选 `element?: string[]`，取值**必须 ⊆ 卡词条元素集**（门禁校验——「AI 只选不改数」的延伸）；
- 结算语义（2026-10-03 修订，落码查证后重锚）：战斗 roll 的克制是**标签制**（行动标签命中意图反制标签 → ⌈威胁/2⌉，skirmish.ts:224），元素不参与 roll 克制；元素轴的结算落点 = **技能轨主轴派生取优**——效果带 element[] 时该效果主轴派生 = max(各元素对应五维值)，不叠加防膨胀（执行任务书 B5.5）；
- 无该字段的效果行为完全不变（旧卡零回归；对 E 批资产是严格超集扩展）；
- 叙事面技能描述可写「火/暗混合」。
- 注：AOE/多敌表达**已存在**（`target:'敌全体'`），本设计不重复建设。

见 §四。CRAFT-1/2 已在并行会话修复。

## 二、端到端验收用例：「愤怨瓷心·艾拉」

> 原始规格（缺口报告 §四），左列＝目标，右列＝本设计达成路径：

```
名称: 愤怨瓷心·艾拉      等级: 11级        品阶: 黑铁级        EXP: 0/400
```

→ 制卡产出召唤卡即诞生实体（D3），黑铁起步（D14）；等级/EXP 在实体账本（D8），管容沿用品阶表。

```
类型: 伙伴               属性: 火/暗        忠诚度: 100
```

→ `词条:['召唤',…元素]`（既有）；忠诚度＝affections[名] 的显示映射（D9），引擎事件可经营到 100。

```
数值: HP 320 / MP 180 / 攻击 72 / 防御 48 / 敏捷 65
```

→ 公式锚定+元素偏置（D7）随等级成长到 11 级的黑铁量级；战斗接管基座（D5）。

```
品相: 完好（外表保留微量装饰性瓷裂纹）
```

→ 卡物性耐久系统（既有 durability/sealed），与实体生命分轨（D6）。

```
【天赋·暴怒源质】[黑铁]  受击或目睹主人受损时攻击+20%
```

→ 实体 talents（D11）：AI 叙事定名与 kind（事件源「玩家受击」已在），引擎定标，进化升标号。

```
【被动·死寂孤瞳】×2、【主动·裂牙炎斩】【主动·情绪投射·怒火】
```

→ 卡的 cardEffects：被动≤2/主动≤2（E 批既有）；范围爆炸＝`target:'敌全体'`（既有）。

```
20MP，180% 火/暗混合伤害 + 流血
```

→ 效果元素轴 `element:['火','暗']`（D15）；MP cost 走 E 批 cost 通道（既有）。

```
性格: 冷酷寡言、对敌残忍果决、对主人极度顺从依恋…
```

→ 制卡叙事提取 personality（D3/D12），进 {{CHARACTER_STATE}} 与 L2 意图软贴合。

```
装备: 【狼牙锯刃】（手部武器）
```

→ 佩戴表手部槽（D10），加算区并入面板。

```
进化倾向: ①熔岩炼狱 ②无心裁决 ③双生重构    进化卡槽: 未解锁
进化潜能: 投喂高阶火/暗/金属类素材可大幅加快进化蜕变
```

→ 仪式型进化（D13）：AI 定制三倾向名；等级达黑铁上限+选倾向后卡槽解锁；祭品类＝火/暗/金属；投喂走 D8 改道。

## 四、五批落地计划

> 每批附可见 UI 面与验收清单；照 A–F 模式出实机测试交接文档；批次交付停下待检。

### 批① 地基（前置：CRAFT-1/2 已修 ✅）

- 实体结构扩展：等级/面板/佩戴表/talents/沉眠标记（CharacterState summon 语义）
- 「获得即诞生」统一入口：制卡/购卡/捕获/掉落 → 按名 ensure；personality 从制卡叙事提取
- 黑铁替换白铁全链（13 张表键名 + 内容包文案排查 + 读取映射）
- 休眠—唤醒生命周期
- **验收**：制一张召唤卡 → 实体立即诞生（{{CHARACTER_STATE}} 可见、黑铁、面板/性格/天赋在位）；卖光卡 → 实体沉眠；买回 → 唤醒续接；普通卡机制零回归

### 批② 战斗接入

- 面板接管基座（skillContextOf/deriveCardAtk 取数改道）
- 挡刀池（玩家受击事件的转移判断：忠诚门槛/被动/招式指定）
- HP 归零退场 + 重伤态；MP/敏捷结算语义
