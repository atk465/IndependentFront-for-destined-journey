# 天赋系统 · 数值总表终审

> **状态**：全部 v1 初稿，待主人逐表过目调参。
> **范围**：交锋拍制 + 天赋骨架 + 品级定价 + 派生数值 + 规则层钩子。
> **原则**：数值归 Code（ADR-11），审计行逐项可复算。

## 1. 交锋拍基础公式

| 参数         | 值                                | 来源/说明                             |
| ------------ | --------------------------------- | ------------------------------------- |
| 反制掷骰     | d20 + 行动值 + 克制加成           | ≥ 威胁 = 反制成功                     |
| 威胁标定锚   | 玩家行动值 ±10                    | 势均力敌 ≈ +10，弱于 ≈ −5，头目 ≈ +15 |
| 敌方 HP 标定 | 单拍伤害 ×4~8                     | 势均力敌略有压力的量级                |
| 碾压速胜线   | 我方战力 ≥ 敌方 ×2                | 女王领域/霸巨人等 statMultiplier 输入 |
| 倒也可斩     | 敌方当前 HP −50%，玩家 HP/MP −90% | 每场限一次                            |
| 品质越一级   | RARITY_LEVELS 索引 +1（封顶传说） | 垃圾摩托等融合突破                    |

## 2. 经验与评级

| 参数         | 值                                                | 说明                            |
| ------------ | ------------------------------------------------- | ------------------------------- |
| 基础经验     | 10 × 敌方等级(TL)                                 | 参考截图公式锚点                |
| 等级差修正   | max(0.2, min(2, 1+(TL−PL)×0.1))                   | TL=敌级 PL=玩家级               |
| 评价倍率     | S=×2.0 / A=×1.5 / B=×1.0 / C=×0.5                 | S=全拍反制且HP损≤25%；碾压封顶S |
| 卡牌经验分成 | 玩家战斗总经验 × 50%                              | 参战卡均分                      |
| 卡牌经验上限 | 白铁200 / 青铜400 / 白银800 / 鎏金1600 / 星辉3200 | 满管→战力+1、清空重攒           |
| 锚点验证     | TL12 vs PL9、S级 → 312 EXP                        | 参考截图实测值                  |

## 3. 派生战斗数值

| 属性       | 公式                              | 锚点说明                                    |
| ---------- | --------------------------------- | ------------------------------------------- |
| 攻击       | 2×str + level                     | str14 Lv9 → 37（截图基础段≈38）             |
| 防御       | 2×con + ⌊level/2⌋                 | con14 Lv9 → 32                              |
| 敏捷       | 2×dex + ⌊level/2⌋                 | dex12 Lv9 → 28                              |
| 出卡行动值 | 攻击 + 2×卡面战力                 | 白铁+2 / 青铜+4 / 白银+6 / 鎏金+8 / 星辉+10 |
| 基础应对   | 强攻=攻击 / 防御=防御 / 闪避=敏捷 | +同名反制标签                               |

## 4. 在场效果（activeEffects）

| 类型   | 效果                           | 持续     |
| ------ | ------------------------------ | -------- |
| dot    | 每拍拍末敌方持续损失 amount HP | beats 拍 |
| buff   | 每拍玩家行动值 +amount         | beats 拍 |
| weaken | 每拍敌方威胁 −amount           | beats 拍 |
| stun   | 敌方本拍放弃行动               | beats 拍 |

领域/装备/召唤 在场卡数量不限，同名不可重打。

## 5. 交锋拍制卡规则

| 规则         | 值                                              |
| ------------ | ----------------------------------------------- |
| 招式轮换上限 | 6 式（MAX_INTENTS），序列打完按原序循环         |
| 拍数上限     | 不限（打到一方倒下或主动收手）                  |
| 碾压速胜线   | 我方战力 ≥ 敌方 ×2 → 跳拍直接结算（评价封顶 S） |
