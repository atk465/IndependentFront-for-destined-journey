# 好感共鸣 + 冒险者等级接入声望 —— 情感数值驱动设计（2026-09-16）

> 状态：已实施（`4e8813a` 好感共鸣 / `3b4965b` 冒险者等级）
> 裁决人：主人
> 关联：精简运动 ADR（命运契约删除时主人裁定「专属词条交给好感度解决」——本文档就是那个解决方案）

## 一、好感共鸣（伙伴卡 × 好感度）

### 裁定

> 主人：好感度**留**，而且伙伴卡要**接入好感度**。

### 绑定规则：名字即羁绊（零配置）

卡名 = NPC 角色名。打出**召唤/军团卡**（伙伴卡）时，查 `SaveProfile.affections`（键 = 角色名）里的同名记录。不引入任何绑定配置——沿用契约召唤时代「角色名 = 卡名」的既有裁定。

### 数值表（`card-workshop/affection-bond.ts` 纯函数）

| 好感 | 标签（affection-system 11 级） | 效果乘区                 |
| ---- | ------------------------------ | ------------------------ |
| ≥90  | 誓死追随                       | ×1.5                     |
| ≥70  | 深厚羁绊                       | ×1.4                     |
| ≥50  | 友好信任                       | ×1.3                     |
| ≥30  | 好感                           | ×1.2                     |
| ≥10  | 略有善意                       | ×1.1                     |
| -9~9 | 中立                           | ×1（不加不减）           |
| ≤-10 | 反感以下                       | **×0.8（伙伴消极怠工）** |

设计要点：奖励档与惩罚档**互斥分离**（首版 bug：把 −100 惩罚档混进升序表导致好感 0 落进 0.8 折——测试逮住后改为 `BOND_TIERS`（只含正向）+ `BOND_PENALTY_THRESHOLD/MULTIPLIER` 两个独立常量）。

### 生效路径（`game-pipeline.submitSkirmishCounter`）

两条出卡路径都接：

- **普通卡**：`cardPlayPlan` 之后，若 kind ∈ {召唤, 军团} 且有共鸣 → `action.power` 与 `activate.amount` 同乘，prepend 审计行
- **封印卡**：`res.effectFired`（启封/暴走效果真发动）时才乘，防「效果炸空还吃加成」

审计行（置于拍审计之前的「意图」行区）：

```
▸ 好感共鸣：与【莉薇娅】的羁绊（友好信任 55）→ 效果 ×1.3
```

### 边界

- 账本无同名记录 → `bondForCard` 返回 null，**沉默**（不出审计行——沉默的多数不值得一行字）
- 记录为 0 → 有效记录，中立 ×1（label 可读，但数值无变化）
- 坏数据（NaN/Infinity）→ 按无记录处理
- 乘区取整：`applyBond = Math.round(value × multiplier)`（交锋数值全整数）

### 测试

`affection-bond.test.ts` 12 条：档位边界、档内取最高、中立区间、惩罚档、超界钳制、结构约束（阈值降序/乘区递减）。

## 二、冒险者等级接入声望

### 裁定

> 主人：改，把冒险者等级接入声望，声望到一定程度后自动更新等级。

### 设计：等级 = 声望的纯派生（不落库）

原 `CharacterState.adventurerRank` 字段（逐角色存字符串）删除。称号是**存档级**身份（声望在 SaveProfile 上），逐角色复制就是第二真相来源。改为纯派生：

```
rankForReputation(声望) → 称号
  0 未评级 → 20 D → 60 C → 150 B → 350 A → 700 S
```

「声望到阈值自动更新」用纯函数映射天然成立——声望一变（委托结算唯一写入口，AI 零写路径），派生结果当场就是新的，**零同步代码**。

### 实施点

| 位置                                     | 内容                                                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `card-workshop/adventurer-rank.ts`（新） | `ADVENTURER_RANK_TIERS` 阈值表 + `rankForReputation` + `nextRankGap`（距下一档差多少，UI 进度用） |
| 阈值标定                                 | 单次委托 4~~15 声望 → D 级约 3~~5 次小委托，S 级需长期经营                                        |
| StatusOverview                           | 冒险者等级行读派生值                                                                              |
| CommissionBoard                          | 声望行显示「公会声望 123 · B 级」                                                                 |
| `stats.主角.冒险者等级`                  | 继续供值（AI/EJS 可读），值改为派生                                                               |
| namespace-normalizer                     | `stat_data.主角.冒险者等级` 别名直指 `profile.reputation` 真源                                    |
| 旧档                                     | `adventurerRank` 字段残留原样保留（无读口，无害）                                                 |

### 测试

`adventurer-rank.test.ts` 7 条：阈值边界、超界、非法输入回落、结构约束（阈值降序无重名）、nextRankGap 三态。
